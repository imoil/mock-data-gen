1개 문서

신규 개발자 온보딩 안내서

mock-data-gen은 데이터베이스나 캐시 없이 SensorId와 시각만으로 결정론적 센서 측정값을 생성하는 Gradle 멀티 프로젝트다. 이 문서는 전체 구조, 로컬 빌드와 검증 절차, example-app 실행과 API 확인 방법, 개발 규칙을 안내한다.

아키텍처 결정 기록 (ADR)

3개 문서

0001. 3-모듈 라이브러리 경계 분리 (Core / Spring Boot Starter / Example App)

Mock data 생성 라이브러리를 외부 프로젝트가 다양한 형태(순수 Java 또는 Spring Boot 웹 애플리케이션)로 참조할 수 있도록 Gradle 멀티 프로젝트를 mock-data-core, mock-data-spring-boot-starter, example-app 3개 모듈로 분리한다.

adr/0001-multi-module-library-boundary.md MD 원문 (.md)

0002. 결정론적 노이즈 입력 통일 및 Starter 설정 커스터마이징

프로젝트사양서.md 4.2절 수식(doubleToLongBits(t_sec))과 6.2절 레퍼런스 코드(sensorSeed ^ timestampMs) 간의 노이즈 해시 입력 불일치를 6.2절 기준으로 통일하고, Starter 설정 프리픽스(app-custom-config.mock.sensor.*) 및 엔드포인트 URI를 외부 프로젝트 규칙에 맞게 변경할 수 있도록 설계한다.

adr/0002-deterministic-noise-and-starter-customization.md MD 원문 (.md)

0003. Starter 라이브러리(ees.mock.sensor.*)와 컨슈머 앱(app-custom-config.*) 프로퍼티 프리픽스 분리

ADR-0002에서 Starter 설정 프리픽스를 app-custom-config.mock.sensor.*로 지정했으나, app-custom-config.*는 본래 컨슈머 애플리케이션이 외부 의존성 설정과 분리해 관리하는 앱 고유 네임스페이스였다. 그 결과 example-app의 운영 컨트롤러와 Starter 설정이 동일 네임스페이스에 섞이는 역방향 결합이 발생했다. 따라서 mock-data-spring-boot-starter의 모든 프로퍼티는 라이브러리 고유 프리픽스 ees.mock.sensor.*로 분리하고, example-app은 컨슈머 앱 고유 설정으로 app-custom-config.sensor.*를 사용하도록 분리한다.

adr/0003-starter-property-prefix-separation.md MD 원문 (.md)
